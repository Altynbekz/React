# React Practice

A blank React page for learning by building. Your exercises are in [TODO.md](./TODO.md).

## Run the page

From this folder, run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Stop the server with **Ctrl+C**.

The blank page is expected! Edit `src/App.js`, save, and refresh the browser to see your work. Keep the browser's developer console open to see errors.

This starter loads React and Babel from the internet, so it needs a connection. Babel lets you write JSX (HTML-like markup inside JavaScript). A later exercise moves the project to a build-tool setup.

## Where to work

- `src/App.js`: your components and application logic. Start here.
- `index.html`: the page that loads React and your app.
- `TODO.md`: practical exercises and checks for each one.

For now, use hooks as `React.useState` and `React.useEffect`. You don't need imports in this starter.

Do one task at a time. Try it yourself first, check the result, and tick its checkbox. Ask for a hint with your task number and code when you're stuck.
